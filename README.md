# Northlight theme

Shopify theme for Northlight (northlightmen.com). Base: Dawn 16.0.0.

Custom code lives in:
- `sections/nl-*.liquid` — Northlight sections (buy box, trust strip, cards, ingredients, reviews slot, tabs, comparison, guarantee, FAQ, final CTA, ticker, legal note)
- `snippets/nl-icon.liquid` — icon set
- `assets/northlight.css`, `assets/northlight.js`
- `templates/product.json` — product page layout

Checkout links (Reign) are set per pack in the theme editor: Product page → NL · Buy box → each Pack block.
